# 경쟁 앱 비교: 한국 Google Play

- 작성: 2026-11-12, marketing (#115). 출시 전 분석 [`planning/market/analysis.md`](../../planning/market/analysis.md)(미국 스토어 기준)을 이어받아 **한국 스토어**(`hl=ko&gl=kr`)를 확인했다.
- 모든 값의 확인 날짜는 **2026-11-12**다. 등록정보 페이지를 브라우저로 열어 본 값이며 바뀔 수 있다.
- 리뷰 불만은 등록정보 첫 화면에 보인 상위 리뷰 몇 개의 요약이다(표본 작음, 2018~2022년 리뷰가 많아 지금 상태와 다를 수 있음). 리뷰 작성자 정보와 개발자 연락처는 옮기지 않았다.
- PiecePlay(`com.gamenuri.pieceplay`)는 같은 날 한국 스토어 상세 주소가 404였다(아직 공개 전).

## 4. 리뷰 불만 (한국 페이지 상위 리뷰 요약)

| 앱 | 불만 | 리뷰 날짜 |
|---|---|---|
| uTorrent | 광고가 나올 때 동영상이 갑자기 재생돼 놀람, 오류로 앱이 꺼짐 | 2019-12 |
| uTorrent | 몇 개 받은 뒤 다운로드가 안 되거나 속도가 0에 가깝게 떨어져 멈춤 | 2018-10 |
| uTorrent | 한글 파일명을 인식하지 못함, 완료 후 멈추거나 파일이 안 보임 | 2019-07 |
| Flud | 업데이트 후 심한 버벅임 | 2019-10 |
| Flud | 처음 쓰는 방법을 알기 어렵고, 마그넷 자동 인식이 잘 안 되고, 토렌트 파일을 수동으로 추가해야 함 → "더 단순했으면" | 2019-08 |
| Flud (긍정) | 외장 SD 저장 시 느려지므로 내장 메모리로 받으라는 팁 | 2019-09 |
| 심플 Torrent | 외장 SD 저장 위치 지정이 안 됨(Android 11 이후 권한) | 2022-01 |
| 심플 Torrent | 외장 메모리에 받은 파일을 찾을 수 없고 지울 수도 없음 | 2022-06 |
| Amnis, Torrent Play | 한국 페이지에 리뷰 표시 없음(미확인). 미국 스토어 Amnis 리뷰 불만은 planning 분석 3절 참고 | — |

PiecePlay에 주는 시사점:
1. **"처음 쓰기 어렵다"·"마그넷 인식이 안 된다"**: PiecePlay는 링크 하나로 시작하는 단순한 흐름이 강점이다. 다만 브라우저 마그넷 링크 인식은 아직 없다([planning/requests/open-links-from-other-apps.md](../../planning/requests/open-links-from-other-apps.md)).
2. **"광고가 갑자기 재생된다"**: 재생 중 광고 없음 정책이 대응한다.
3. **"받은 파일을 못 찾는다"·저장 위치**: PiecePlay도 앱 전용 저장소라 같은 불만이 나올 수 있다. "저장 파일 관리"에서 보고 지운다는 점을 설명에 분명히 쓴다. 내보내기는 [export-to-device.md](../../planning/requests/export-to-device.md).
4. **한글 파일명**: 자동완성 "토렌트 한글"과 연결된 불만으로 보인다. PiecePlay 처리 여부는 미확인 → program 확인 후 강점이면 설명에 쓴다.

## 5. 광고 방식

| 앱 | 방식 | 근거 |
|---|---|---|
| uTorrent | 광고 + 인앱 구매, 유료 Pro로 제거. 위치 권한을 "위치 관련 광고"용으로 요청 | 등록정보 설명(선택 접근 권한 절) |

| 심플 Torrent | 광고 + 인앱 구매 | 등록정보 상단 |
| **PiecePlay** | 배너는 메인·재생 목록만, 전면은 재생 종료·완료 시 조건부(5분 이상 시청 또는 5회 완료, 10분 간격). 재생·준비·버퍼링 중 없음. 제거 결제 없음 | 루트 `CLAUDE.md` 광고 절 |
