# 비용 없는 홍보 채널 후보 (한국 출시)

- 작성: 2026-11-12, marketing (#115)
- **이 문서는 후보 정리다. 아무것도 게시하지 않았다.** 게시는 사용자가 하거나 사용자 승인 후에 한다(`marketing/CLAUDE.md`).
- 각 커뮤니티의 홍보 규칙은 이번에 원문을 확인하지 않았다(**미확인**). 게시 전에 그 게시판 공지를 사용자가 직접 확인하고, 확인 결과를 이 문서에 적는다.

## 0. 모든 채널 공통 원칙

PiecePlay는 "토렌트"를 다루므로 홍보 문안 하나가 곧 "불법 다운로드 앱"으로 읽힐 수 있다. Play 지식재산권 정책은 **등록정보와 홍보가 무단 다운로드를 부추기는지**를 본다(planning 분석 6절).

| 원칙 | 구체적으로 |
|---|---|
| 금지 표현 | 영화·드라마 제목, 토렌트 사이트 이름, "무료 영화", "최신 개봉작", "무제한 다운로드". "공짜로 본다", "다운 안 받고 본다"도 쓰지 않는다 |
| 데모 영상 | Blender 오픈 무비(Sintel, Big Buck Bunny, Tears of Steel)나 직접 찍은 영상만. 화면에 CC BY 표기(© Blender Foundation | www.blender.org) |
| 링크 예시 | 실제 저작권 콘텐츠 마그넷을 보여 주지 않는다. 예시가 필요하면 공개 라이선스 콘텐츠(Blender 오픈 무비 등)만 쓴다 |
| 강조점 | 기술·사용성(받으면서 재생, 탐색 위치 먼저 받기, 업로드 없음, 재생 중 광고 없음, 기기 안 암호화) |
| 권리 안내 | 모든 글 끝에 "권리를 가진 콘텐츠만 재생해 주세요" 한 줄 |
| 반복 게시 | 같은 글을 여러 게시판에 동시에 올리지 않는다(도배로 신고될 수 있음) |
| 개발자 신분 | 개발자 본인이 쓴 글임을 밝힌다(숨은 홍보는 커뮤니티 규칙·표시광고 문제) |
| 리뷰 유도 | 보상 대가 리뷰 요청 금지(Play 정책). "써 보고 의견 주세요"까지만 |

## 2. 첫 주 실행 순서 제안 (PM 결정)

1. 사용자가 데모 화면 녹화(Blender 오픈 무비, 20초 내외)를 만든다. 재생 중 광고 없음·탐색 시 바로 재생을 보여 준다.
2. 블로그 개발기 1편(marketing이 초안 작성 → 사용자 검토 → 사용자가 게시).
3. GeekNews Show GN에 블로그 링크로 소개(사용자 게시).
4. X/Threads에 데모 영상(사용자 게시).
5. D7 지표([`../reports/launch-week-checklist.md`](../reports/launch-week-checklist.md))에서 외부 유입이 생겼는지 확인 후 다음 채널 결정.

## 3. 문안 초안 (게시 전 사용자 검토)

### 짧은 소개 (SNS용, 약 120자)

```
안드로이드 앱 PiecePlay를 출시했습니다. 마그넷 링크를 붙여넣으면 다 받기 전에 바로 재생하고, 이동한 위치부터 먼저 받습니다. 업로드는 하지 않고, 재생 중에는 광고가 없습니다. (데모: Blender 오픈 무비, CC BY)
```

### 블로그 개발기 목차

1. 왜 만들었나: 다 받을 때까지 기다리는 불편
2. 재생 위치를 따라가는 조각 우선순위(순차 다운로드와 차이)
3. 탐색하면 그 구간을 먼저: Range 요청과 해시 검증
4. 업로드하지 않는 클라이언트로 만든 이유
5. 재생 화면에 광고를 넣지 않은 이유
6. 기록을 기기 안에 암호화한 방법(Android Keystore)
7. 권리를 가진 콘텐츠만 재생해 달라는 안내, Play 링크

## 결정 필요 (PM·사용자)

- 블로그 플랫폼과 개발자 계정(새 계정 생성은 사용자가 한다)
- 데모 영상 제작 주체(사용자 녹화 vs design)
- 커뮤니티 3·5번의 공지 확인 결과에 따라 게시 여부
