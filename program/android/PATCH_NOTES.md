# PiecePlay 패치 노트

## 다음 배포 준비

- 재생 화면 위쪽에 자막 버튼을 두었습니다. 누르면 영상 안 자막·음성 트랙과 토렌트 안에서 함께 받은 자막 파일(.srt·.smi 등, "파일" 표시)을 아래 시트에서 고를 수 있고, 고르는 동안 영상은 계속 재생됩니다. 아직 받는 중인 자막 파일은 "받는 중"으로 보입니다.
- 설정 "자막 자동 표시"가 켜져 있으면 마지막으로 고른 언어(처음에는 한국어) 자막을 자동으로 켜고 "자막: 한국어(파일)" 같은 알림을 잠깐 보여 줍니다. 기기 언어가 한국어이면 EUC-KR로 저장된 .smi·.srt 자막도 읽습니다.
- 토렌트 안에서 영상과 그 자막 파일만 받습니다. 시즌 팩(회차 표시 SxxEyy)에서는 그 회차의 자막만 고르고, "1080p.WEB" 같은 화질 표시가 달라도 같은 회차 자막으로 봅니다.
- 화면 확대·축소 버튼을 더보기 메뉴의 "화면 확대"로 옮겼습니다. 배율이 1.0×가 아닐 때만 위쪽에 배율 칩이 보이고, 누르면 1.0×로 돌아갑니다.
- Wi-Fi 전용인데 재생 중 모바일 데이터로 바뀌면 "모바일 데이터로 재생 중" 알림을 한 번 보여 줍니다.
- 재생 화면의 속도·피어 칩 글자를 흰색으로 바꿔 밝은 영상 위에서도 잘 보이게 했습니다.
- 브라우저·메신저에서 마그넷 링크를 누르거나 다른 앱에서 링크를 공유하면 앱이 열리고 "이 링크를 열까요?" 확인 시트가 뜹니다. 영상 이름(또는 줄인 주소)을 보고 [바로 재생] [받아 두기] [취소] 중에서 고릅니다. 고르기 전에는 아무것도 시작하지 않고, 받은 링크는 메인 입력란에도 채워집니다.
- 재생 목록에 있는 링크면 상태 칩과 "재생 목록에 있는 영상입니다." 안내가 보이고, 이어볼 위치가 있으면 [이어서 재생]이 나옵니다. 다 받았거나 받는 중이면 [받아 두기]는 보이지 않습니다.
- 재생·준비 중에 링크가 들어오면 재생을 끊지 않고 [받아 두기] [취소]만 보입니다.
- 받아 두면 메인 입력란을 비우고 "재생 목록에 추가했습니다." 알림과 재생 목록 바로 가기가 나옵니다. Wi-Fi 전용이 켜진 채 모바일 데이터라면 "Wi-Fi에 연결되면 받기 시작합니다."가 나옵니다. 재생·준비 화면에서는 영상을 가리지 않도록 알림을 띄우지 않습니다.
- 링크 확인 시트의 상태 칩은 재생 목록 카드와 같습니다("Wi-Fi 대기" 포함).
- 열 수 없는 링크(지원하지 않는 주소, 형식이 틀린 마그넷, 너무 긴 링크, https가 아닌 주소)는 이유를 알려 주는 시트로 안내합니다.
- 인코딩되지 않은 한글 이름이 들어 있는 마그넷, 대문자로 쓴 `HTTPS://` 주소도 받습니다. 아주 긴 공유 글에서 끝이 잘린 링크는 열지 않습니다.
- 재생 목록 항목 하나가 깨져도 나머지 항목은 그대로 보입니다.
- 설정 화면을 추가했습니다. 메인 오른쪽 위 톱니를 누르면 열리고, 다운로드(Wi-Fi 전용), 재생(자막 자동 표시), 정보(이용 안내, 개인정보처리방침, 오픈소스 라이선스, 필요한 지역에서 광고 개인정보 설정, 버전) 묶음이 있습니다. 메인 하단 링크는 그대로 둡니다. 설정에서 연 오픈소스 라이선스는 뒤로 가면 설정으로 돌아옵니다.
- Wi-Fi 전용이 켜져 있으면 재생 목록에서 모바일 데이터 때문에 멈춘 항목에 "Wi-Fi 대기" 칩이 붙고 속도는 숨기며 "중지"로 대기에서 뺄 수 있습니다. 요약 줄에 "· Wi-Fi 대기 N개"가 붙습니다.
- Wi-Fi 전용이 켜진 채 모바일 데이터에서 덜 받은 영상을 재생하면 "이번만 모바일 데이터로 재생할까요?" 확인 창이 뜹니다. [이번만 재생]은 이 재생만 허용하고 설정은 바꾸지 않으며, [취소]는 아무것도 시작하지 않습니다.
- 설정을 저장하지 못하면 스위치가 원래 값으로 돌아가고 "설정을 저장하지 못했습니다. 다시 눌러 주세요." 안내가 나옵니다.
- Wi-Fi 전용이 켜진 채 모바일 데이터에 연결되어 있으면 설정의 Wi-Fi 전용 아래에 "모바일 데이터에 연결되어 다운로드를 멈췄습니다. Wi-Fi에 연결되면 이어서 받습니다." 안내가 보입니다.
- 이때 재생 목록의 다운로드나 링크 추가 창으로 받기를 시작하면 항목이 바로 Wi-Fi 대기로 들어가고 "Wi-Fi에 연결되면 받기 시작합니다." 안내가 나옵니다(재생·준비 화면에서는 영상을 가리지 않도록 띄우지 않습니다).
- 이용 안내의 데이터 사용 문구가 설정의 Wi-Fi 전용을 권하도록 바뀌었습니다.

- 오픈소스 라이선스 화면(목록과 라이선스 전문)을 추가했습니다.
- 메인 화면 아래에 "이용할 권리가 있는 콘텐츠만 재생하세요." 안내와 이용 안내 · 개인정보처리방침 · 오픈소스 라이선스 · (필요한 지역에서) 광고 개인정보 설정 링크, 버전을 둡니다. 개인정보처리방침은 웹 브라우저로 열리고, 브라우저를 열 수 없으면 안내가 나옵니다.
- 이용 안내를 아래에서 올라오는 시트로 추가했습니다: 저작권 안내, 앱이 받는 것과 올려 보내지 않는 것(연결된 사용자에게 IP 주소가 보인다는 점 포함), 기기 안 저장, 데이터 사용, 광고.
- 토렌트 처리 중 예기치 않은 오류가 나면 영어·라이브러리 원문 대신 "토렌트를 처리하지 못했습니다. 잠시 후 다시 시도해 주세요."가 나옵니다(메인 오류, 재생 목록의 다운로드 오류).
