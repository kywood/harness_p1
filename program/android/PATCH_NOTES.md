# PiecePlay 패치 노트

## v.2026.11.12.002 (versionCode 27)

- 앱 전체를 남색 배경과 파랑→민트 브랜드 색의 다크 테마로 바꿨습니다(기기 배경화면 색에 따라 바뀌지 않음).
- 메인 화면에 링크 붙여넣기 버튼과 재생 목록·저장 파일 관리 카드를 두고, 준비 화면에 정보 → 연결 → 버퍼링 단계와 진행 막대·피어 수를 보여 줍니다.
- 재생 목록·저장 파일 관리를 새 디자인으로 바꿨습니다: 상태 칩과 진행 막대가 있는 항목 카드, 정렬·표시 칩, 한 줄에 모인 일괄 선택 동작, 형식 아이콘이 있는 파일 행, 같은 모양의 링크 추가·삭제 확인 창. 주요 버튼 글자가 더 잘 보이도록 버튼 색을 조금 어둡게 했습니다.
- 재생 화면 조작 UI를 새 디자인으로 바꿨습니다: 위·아래 그라데이션 가림막, 재생한 구간(파랑→민트)과 받은 구간이 함께 보이는 재생 막대, 같은 크기의 아이콘 버튼, 아래에서 올라오는 더보기 메뉴, 경고 아이콘이 있는 오류 화면.

## v.2026.11.12.001 (versionCode 26)

- 재생 위치 앞쪽을 조각 4개가 아니라 약 30초 분량(최대 64MB)만큼 먼저 받습니다. 조각이 작거나 고화질 영상에서도 재생 중 끊김이 줄어듭니다.
- 영상 제목 저장에 실패해도 앱이 종료되지 않습니다.
- 검증: 단위 테스트 260개, 에뮬레이터 테스트 31개 및 디버그 빌드·lint 통과.

- 재생 취소·뒤로가기·다운로드 중지 시 화면이 잠시 멈추던 문제를 고쳤습니다. 이어받기 저장과 연결 정리는 백그라운드에서 진행합니다.
- 검증: 단위 테스트 236개, 에뮬레이터 테스트 28개 및 디버그 빌드 통과.
- 받은 영상과 이어받기 기록을 캐시가 아닌 앱 저장 공간에 보관합니다. 저장 공간 부족이나 캐시 삭제로 영상이 사라지지 않습니다. 기존 파일은 첫 실행 때 자동으로 옮깁니다.
- 검증: 단위 테스트 241개, 에뮬레이터 테스트 28개 및 디버그 빌드 통과.
- 다운로드가 끝난 영상은 즉시 공유를 멈춥니다. 재생 중에도 다른 사용자에게 완성본 보유자로 알려지지 않습니다. 기존처럼 업로드는 하지 않고, 선택한 영상 외의 파일은 받지 않습니다.
- 검증: 단위 테스트 241개, 에뮬레이터 테스트 29개 및 디버그 빌드 통과.
- 버퍼링·탐색·뒤로가기·다운로드 시작과 중지 때 버튼이 멈추던 현상을 고쳤습니다. 토렌트 엔진과 플레이어 정리 작업을 화면 밖에서 처리합니다.
- 검증: 단위 테스트 244개, 에뮬레이터 테스트 31개 및 디버그 빌드 통과.
- 평문(HTTP) 통신은 앱 안의 영상 스트림 주소에만 허용합니다. http:// 토렌트 파일 링크는 자동으로 https:// 로 받습니다.
- 검증: 단위 테스트 248개, 에뮬레이터 테스트 31개 및 디버그 빌드·lint 통과.
- 오류 안내와 재생 화면 버튼 등 영어로 나오던 문구를 한국어로 바꿨습니다(예: 바로 재생, 돌아가기, 토렌트 정보를 가져오지 못했습니다).
- 검증: 단위 테스트 251개, 에뮬레이터 테스트 31개 및 디버그 빌드·lint 통과.
- 광고를 보여 주기 전에 Google 동의 절차(UMP)를 거칩니다. 동의가 필요한 지역에서는 동의 창이 뜨고, 메인 화면에 광고 개인정보 설정이 표시됩니다.
- 검증: 단위 테스트 252개, 에뮬레이터 테스트 31개 및 디버그 빌드·lint 통과.

- 첫 마그넷 연결은 같은 핸들을 최대 120초 유지하며 메타데이터를 직접 확인합니다.
- 피어 0명 상태가 5초 지속되면 DHT·트래커 탐색을 다시 요청하고 재요청 간격을 늘립니다.
- 메타데이터 수신 후 별도의 이어받기 데이터 저장 응답을 기다리지 않습니다.
- 피어 탐색 경과 시간 표시, 취소 시 임시 핸들 정리, 기존 다운로드 보호를 추가했습니다.
- 메타데이터 수정 검증: 단위 테스트 211개·네이티브 통합 테스트 7개, 디버그·출시용 APK 빌드 통과.

- VLC·광고 SDK가 간접 참조하는 Fragment를 1.9.1로 명시했습니다.
- 구형 Fragment 1.0.0/1.1.0 대신 최신 안정 버전을 사용합니다.
- 앱 버전 증가는 다음 배포 시 함께 진행합니다.
- 검증: Fragment 1.9.1 의존성 해석, 단위 테스트 204개·에뮬레이터 테스트 15개 및 APK/AAB 빌드 통과.

## v.2026.11.01.008 (versionCode 18)

- 재생 준비 중 `재생 목록`으로 이동해도 같은 다운로드를 계속 유지합니다.
- `메인`으로 이동하면 현재 다운로드만 중지하고 다른 다운로드는 유지합니다.
- 여러 다운로드를 함께 관리하고 대기 중인 작업을 순서대로 시작합니다.
- 다운로드 작업들이 하나의 libtorrent 세션을 공유하도록 개선했습니다.
- 전체 선택 후 다운로드 시 발생하던 네이티브 충돌을 수정했습니다.
- 선택 작업을 `전체 선택 · 삭제 · 다운로드/중지` 한 줄로 정리했습니다.
- 재생 목록에 최근 재생순·받은 날짜순 정렬과 완료 여부 필터를 추가했습니다.
- 완료 파일 재생 전환 및 다운로드 파일 삭제 시 작업 간 충돌을 개선했습니다.
- 가로 화면의 재생 정보와 피스 범례를 간결하게 표시합니다.
- 재생 UI가 보일 때만 좌우 스와이프로 탐색하고 확대 화면 이동은 유지합니다.
- 준비 화면 버튼을 `메인`과 `재생 목록`으로 구분했습니다.
- 날짜와 당일 수정 횟수에 따른 버전 관리 및 APK/AAB 출력 기능을 추가했습니다.

검증: 단위 테스트 201개, 관련 에뮬레이터 테스트 11개 통과(v007 코드 기준).
출시 빌드: v008 버전 검증·단위 테스트 201개·서명 APK/AAB 빌드 통과.
