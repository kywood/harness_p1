# 스토어 등록정보 한국어(ko-KR) 초안

대한민국 단독 출시용 기본 등록정보 초안이다. Play Console의 현재 문구가 저장소에 없어서 앱 화면(v.2026.11.12.002 이후 main)과 #49 스토어 그래픽 문구를 기준으로 썼다. 입력 전에 Console 현재 문구와 대조하고, 바꾼 최종본을 이 파일에 다시 적는다.

피하는 표현: 영화·드라마 제목, 토렌트 사이트 이름, "무료 영화", "최신 개봉작", "무제한 다운로드".

스크린샷: `launch/store-assets/*/ko-KR`는 2026-11-14에 v.2026.11.14.001 빌드(한국어 UI)로 다시 찍어 영어와 같은 7장 구성으로 바꿨다(재생 가로 → 메인 → 이동 → 재생 목록 → 링크 열기 → 자막 → 저장 파일, 준비 장면은 뺐다). 캡션은 `launch/store-assets/README.md` "캡션" 표, 근거는 `marketing/reports/store-screenshots-en-2026-11.md`. 화면 속 영상은 Sintel, Big Buck Bunny, Tears of Steel이라 아래 출처 문장과 맞는다. 예전 4번 캡션의 "확대 · 축소"는 화면에 보이지 않아 뺐다.

## 앱 이름 (30자 이내)

```
PiecePlay - 토렌트 플레이어
```

(20자. Google Play에 게시된 제목이다. 사용자 결정 2026-11-14: 그대로 둔다.)

## 간단한 설명 (80자 이내)

```
마그넷이나 .torrent 링크를 넣으면 다 받기 전에 바로 재생합니다.
```

## 자세한 설명 (4000자 이내)

```
PiecePlay는 영상을 받으면서 바로 재생하는 플레이어입니다. 마그넷 링크나 .torrent 파일 주소를 붙여넣으면 영상 앞부분이 준비되는 대로 재생을 시작합니다.

받으면서 바로 재생
• 재생 위치 바로 앞부분부터 먼저 받아 기다림을 줄입니다.
• 원하는 곳으로 이동하면 그 위치부터 다시 받습니다.
• 다운로드 조각 맵과 재생 막대로 받은 부분과 본 부분을 한눈에 확인합니다.
• 토렌트 안에서 영상과 그 자막 파일만 받습니다. 다른 사용자에게 업로드하지 않고, 다 받으면 바로 연결을 끊습니다.

다른 앱의 링크 열기
• 브라우저나 메신저에서 마그넷 링크를 누르거나 링크를 PiecePlay로 공유하면 확인 창이 뜹니다. 바로 재생, 받아 두기, 취소 중에서 고르세요.

자막
• 재생 중에 자막과 음성 트랙을 고를 수 있습니다. 영상과 함께 받은 자막 파일도 고를 수 있습니다.
• 설정의 "자막 자동 표시"를 켜 두면 내 언어 자막이 있을 때 바로 켜집니다.

재생 목록과 저장 공간
• 최근 링크 50개를 재생 목록에 보관하고, 보던 곳부터 이어봅니다.
• 영상은 최대 3개까지 동시에 받고, 나머지는 대기열에서 차례를 기다립니다.
• 받아 두는 영상의 "받는 순서"를 설정에서 고를 수 있습니다. "앞부분부터"는 받는 중에도 바로 재생하기 쉽고, "빠르게 받기"는 받을 수 있는 조각부터 받습니다. 재생 목록에서 영상마다 따로 정할 수도 있습니다.
• 저장 파일 관리에서 형식별로 파일을 모아 보고 바로 삭제합니다.

모바일 데이터 아끼기
• 설정에서 "Wi-Fi 전용"을 켜면 모바일 데이터에서는 다운로드를 멈추고, Wi-Fi에 연결되면 이어서 받습니다.
• 모바일 데이터에서 영상을 재생하려고 하면 먼저 물어봅니다.

개인정보
• 재생 목록, 이어보기 위치, 받은 영상은 기기 안에만 저장됩니다. 재생 목록과 이어보기 정보는 암호화합니다.
• 회원가입이 없고 개발자 서버로 보내는 정보도 없습니다.
• 앱에는 Google AdMob 광고가 포함되어 있습니다. 동의가 필요한 지역에서는 먼저 동의를 묻고, 메인 화면이나 설정의 "광고 개인정보 설정"에서 선택을 바꿀 수 있습니다.
• 토렌트 특성상 받는 동안 IP 주소가 같은 토렌트의 다른 사용자에게 보입니다.

PiecePlay는 콘텐츠를 제공하거나 찾아 주지 않습니다. 권리를 가진 콘텐츠만 받고 재생해 주세요.

```

- 빌드 32(v.2026.11.14.003) 기준으로 2026-11-14에 고쳤다(#144). 범위는 `launch/listing/en-US.md` 자세한 설명과 같고, 영어에도 같은 날 "받는 순서" 한 줄을 넣었다.
