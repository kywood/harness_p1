# 요구사항: 모바일 데이터 사용 안내와 Wi-Fi 전용 설정

## 1. 문제
영상 토렌트는 수 GB를 받는다. 모바일 데이터로 연결된 사용자가 모르고 재생·다운로드하면 데이터 요금 폭탄을 맞을 수 있다. 앱은 연결 종류를 구분하지 않고, 경고도 설정도 없다. 이런 경험은 1점 리뷰로 이어지기 쉽다.

## 2. 원하는 동작
1. 모바일 데이터(데이터 제한 연결 포함)에서 처음 "바로 재생"이나 "다운로드"를 누르면 한 번 묻는다: "모바일 데이터로 받고 있습니다. 영상 크기만큼 데이터가 쓰일 수 있습니다." [계속] [Wi-Fi에서만 받기].
2. "Wi-Fi에서만 받기"를 고르면 설정이 켜진다. 켜진 상태에서는 모바일 데이터일 때 재생 목록 다운로드를 "Wi-Fi 대기"로 두고, 바로 재생은 확인 창을 다시 띄운다.
3. 설정 화면(새로 생김, 메인의 톱니 아이콘)에서 "Wi-Fi에서만 다운로드"를 켜고 끌 수 있다.
4. 준비 화면 세부 정보에 연결 종류(Wi-Fi/모바일)를 보인다.

## 3. 완료 조건
- 모바일 데이터에서 처음 재생할 때 확인 창이 한 번 뜨고, 같은 선택을 다시 묻지 않는다.
- Wi-Fi 전용이 켜진 상태에서 Wi-Fi가 끊기면 재생 목록 다운로드가 "Wi-Fi 대기"로 바뀌고, 다시 연결되면 이어진다.
- 설정 값은 앱을 다시 실행해도 유지된다.

## 4. 범위 밖
- 속도 제한(최대 다운로드 속도) 설정, 데이터 사용량 통계

## 5. 영향
- design: 확인 창, 설정 화면(앱 첫 설정 화면이므로 구조 정의 필요), "Wi-Fi 대기" 상태 칩(M)
- program: 연결 종류 감시(`ACCESS_NETWORK_STATE` 이미 있음), 대기 상태 추가, 설정 저장(M)
- 정책: 권한 추가 없음. 기기 안 설정 값 추가만. 데이터 보안 신고 변경 없음.
- 용어: "설정", "Wi-Fi 대기"를 용어 표에 추가 요청.
