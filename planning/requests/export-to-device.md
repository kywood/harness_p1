# 요구사항(새 기능 제안): 받은 영상 내보내기·다른 앱으로 열기

출처: [market/analysis.md](../market/analysis.md) §3·§8 — 범용 클라이언트는 저장 위치를 고르게 하고, Amnis 리뷰에 "다 받은 파일을 다운로드 폴더에 저장·외부 플레이어로 열기" 요청이 있다.

## 1. 문제
다 받은 영상은 앱 전용 저장소에만 있다. 사용자는 그 파일을 갤러리·다른 플레이어·PC로 옮길 수 없고, 앱을 지우면 함께 사라진다. 자기 영상(예: 직접 올린 영상, 공개 라이선스 영상)을 받은 사용자도 꺼낼 방법이 없다.

## 2. 원하는 동작
1. 재생 목록에서 "완료" 항목의 메뉴에 "기기에 저장"과 "다른 앱으로 열기"가 있다.
2. "기기에 저장": 시스템 저장 위치 선택 창(문서 선택기)이 열리고, 고른 위치(예: Download)에 영상 파일을 복사한다. 진행 표시와 완료 알림을 보인다. 앱 안 사본은 그대로 둔다.
3. "다른 앱으로 열기": 설치된 동영상 앱 목록이 뜨고, 고른 앱에서 바로 재생한다(파일 공유 권한만 일시 부여).
4. 미완료 항목에는 두 메뉴가 보이지 않는다.

## 3. 완료 조건
- 완료된 영상을 Download 폴더에 저장하고, 파일 관리자에서 같은 크기로 보인다.
- "다른 앱으로 열기"로 VLC 등 다른 플레이어에서 재생된다.
- 저장소 권한(`READ/WRITE_EXTERNAL_STORAGE`, `MANAGE_EXTERNAL_STORAGE`)을 요청하지 않는다.

## 4. 범위 밖
- 기본 저장 위치를 외부로 바꾸기, 받는 중 파일 내보내기, 자동 내보내기

## 5. 영향
- design: 항목 메뉴, 저장 진행 표시(S)
- program: 문서 선택기로 복사, 파일 공유(FileProvider)(S~M)
- 정책: 권한 추가 없음. 데이터 보안 신고 변경 없음. 다만 [Play 지식재산권 정책](https://support.google.com/googleplay/android-developer/answer/9888072?hl=en)이 "저작권 콘텐츠의 로컬 사본을 무단으로 내려받게 하는 스트리밍 앱"을 위반 예시로 든다. 받은 파일을 앱 밖으로 꺼내는 기능은 이 문구와 맞닿으므로, **출시 후 정책 상황을 보고** 이용 안내([policy-notice-and-privacy.md](policy-notice-and-privacy.md))와 함께 검토한다. 스토어 설명에서 "영화 저장" 같은 표현은 쓰지 않는다.

## 결정 필요
- 도입 여부와 시점(정책 위험 판단은 PM·launch)
