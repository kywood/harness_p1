# 요구사항: 재생 속도와 화면 비율

## 1. 문제
- 강의·다큐를 빨리 보거나 천천히 보고 싶은 사용자가 속도를 바꿀 수 없다.
- 영상은 항상 화면 안에 맞춤(`SURFACE_BEST_FIT`)으로만 나온다. 가로 화면에서 위아래·좌우 검은 띠를 없애려면 손가락 확대로 맞춰야 하고, 영상을 다시 열면 배율이 1배로 돌아간다.

## 2. 원하는 동작
1. 더보기 시트에 "재생 속도"가 있다: 0.5×, 0.75×, 1.0×, 1.25×, 1.5×, 2.0×. 1.0×가 아니면 상단 통계 칩 옆에 현재 속도를 작게 보인다.
2. 더보기 시트(또는 상단 배율 버튼 길게 누르기)에 "화면 비율"이 있다: 맞춤 / 채움(잘림) / 늘림 / 16:9 / 4:3.
3. 화면 비율 선택은 앱 전체 설정으로 기억한다. 속도는 영상을 닫으면 1.0×로 돌아온다.

## 3. 완료 조건
- 2.0×에서 소리가 함께 빨라지고 음 높이가 유지된다(VLC 기본 동작, 미확인 → 검증 필요).
- "채움"에서 가로 화면 검은 띠가 없어진다.
- 앱을 다시 실행해도 화면 비율 선택이 유지된다.
- 속도 변경이 버퍼링 창(재생 위치 앞 약 30초)에도 반영되어, 2.0×에서 끊김이 1.0×보다 크게 늘지 않는다.

## 4. 범위 밖
- 0.1× 단위 자유 속도, 영상별 화면 비율 기억

## 5. 영향
- design: 시트 항목·현재 값 표시(S)
- program: VLC 속도·비율 설정, 엔진 긴급 구간을 속도에 맞춰 늘리기(engine 작은 변경), 설정 저장(S)
- 정책: 기기 안 설정 값만 추가. 데이터 보안 신고 변경 없음.
