# 요구사항(새 기능 제안): 광고 제거 결제

출처: [market/analysis.md](../market/analysis.md) §4 — µTorrent·BitTorrent(Pro $2.99), Flud(유료판), TVS(인앱 결제)가 모두 광고 제거를 판다.

## 1. 문제
광고를 싫어하지만 앱은 계속 쓰고 싶은 사용자가 돈을 내고 광고를 없앨 방법이 없다. 앱의 수익원도 광고 하나뿐이다.

## 2. 원하는 동작
1. 메인 하단(또는 설정)에 "광고 제거"가 있다. 누르면 가격과 "배너와 재생 후 광고가 모두 사라집니다"가 보이고 Google Play 결제 창으로 간다.
2. 결제가 끝나면 즉시 배너·전면 광고가 사라진다. 앱을 다시 설치해도 "구매 복원"으로 되살릴 수 있다(같은 Google 계정).
3. 결제한 사용자에게는 광고 동의(UMP) 창도 필요 없으면 띄우지 않는다(program·launch 확인).
4. 일회성 구매(구독 아님)로 한다.

## 3. 완료 조건
- 테스트 계정으로 구매하면 메인·재생 목록 배너와 재생 후 전면 광고가 보이지 않는다.
- 앱 삭제 후 재설치해도 구매가 복원된다.
- 결제 실패·취소 시 광고 상태가 바뀌지 않고 문구가 보인다.

## 4. 범위 밖
- 구독, 프리미엄 기능 묶음(자막·Chromecast 유료화 등)
- 광고 노출 규칙 자체 변경

## 5. 영향
- design: 광고 제거 안내 화면·버튼(S)
- program: Google Play Billing 연결, 구매 상태 확인·복원, 광고 표시 정책에 구매 상태 반영(M)
- 정책
  - **외부 의존성 추가**(Play Billing Library) → 사용자 승인 필요.
  - Play Console: 인앱 상품 등록, 판매자 계정(결제 프로필) 필요. 등록정보에 "인앱 구매 포함" 표시가 붙는다.
  - 데이터 보안 신고: "구매 기록" 항목 신고가 필요할 수 있다(launch 확인).
  - 광고 노출 조건이 사용자별로 달라지므로 `TestAdPolicy`·`CompletionAdPolicy` 규칙 문서 갱신 필요.

## 결정 필요
- 수익 모델(광고만 / 광고 + 제거 결제)과 가격
- 판매자 계정 준비 여부(개인정보는 `launch/private/`)
