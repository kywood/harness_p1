# 요구사항: 개인정보처리방침·이용 안내(합법 콘텐츠) 진입점

## 1. 문제
- 앱에 AdMob·UMP SDK가 있어 광고 ID 등 기기 식별 정보가 수집된다. Google Play 사용자 데이터 정책은 개인정보처리방침을 스토어 등록정보와 **앱 안**에 둘 것을 요구한다. 지금 앱 안에 링크가 없고, `launch/`에도 개인정보처리방침 문서가 없다.
- 토렌트 클라이언트는 Play 지식재산권 정책 심사에서 "저작권 침해 조장" 여부를 본다. 앱 안에 "권리가 있는 콘텐츠만 재생하라"는 안내가 전혀 없다.
- 사용자도 앱이 무엇을 저장하고 무엇을 보내는지(업로드하지 않음, 기기 안 암호화) 알 곳이 없다. 이것은 이 앱의 장점인데 드러나지 않는다.

## 2. 원하는 동작
1. 메인 하단(버전명 옆 또는 아래)에 "개인정보처리방침"과 "이용 안내"가 있다.
2. "개인정보처리방침"은 웹 페이지(외부 브라우저)로 연다. 내용: 앱 자체는 서버로 데이터를 보내지 않음, 재생 목록·진행 정보는 기기 안에 암호화 저장, 광고 SDK가 수집하는 항목, 삭제 방법(앱 삭제·재생 목록 삭제), 연락처.
3. "이용 안내"는 앱 안 화면 또는 시트로 연다. 내용: 앱이 하는 일(선택한 영상 하나만 받음, 업로드하지 않음, 완료 후 공유 중단), 권리가 있는 콘텐츠만 재생할 책임이 사용자에게 있다는 문장, 저장 위치와 정리 방법.
4. 첫 실행 안내([first-run-guide.md](first-run-guide.md))의 마지막 장에서도 같은 이용 안내 문장을 한 줄 보여 준다.

## 3. 완료 조건
- 메인에서 두 번 이하의 탭으로 개인정보처리방침 URL이 열린다.
- 개인정보처리방침 URL이 Play Console 등록정보의 URL과 같다.
- 이용 안내에 "권리가 있는 콘텐츠만" 취지 문장이 있다.
- 배너·전면 광고 노출 조건은 바뀌지 않는다.

## 4. 범위 밖
- 이용약관 동의 절차(체크박스 강제), 신고 기능, 콘텐츠 필터링
- 개인정보처리방침 호스팅 방법 결정(launch·PM)

## 5. 영향
- design: 메인 하단 링크 배치와 이용 안내 화면 문구(S)
- program: 링크 열기, 안내 화면(S)
- launch: 개인정보처리방침 문안 작성·호스팅, 데이터 보안 양식과 내용 일치 확인
- 정책: **출시 심사 위험을 줄이는 변경**. 데이터 수집 항목은 바뀌지 않으므로 데이터 보안 신고 변경 없음. 외부 브라우저 열기는 권한 불필요.

## 결정 필요
- 개인정보처리방침 호스팅 위치(GitHub Pages, Google Sites 등)와 연락 이메일(개인정보이므로 `launch/private/` 기준으로 결정)
- 이용 안내를 앱 안 화면으로 둘지, 같은 웹 페이지의 다른 절로 둘지
