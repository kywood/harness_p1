# 요구사항: 긴 영상에서 정밀한 탐색

## 1. 문제
가로 스와이프 탐색은 화면 너비 전체가 영상 전체 길이에 대응한다(`SwipeSeek`). 2시간 영화를 세로 화면(약 400dp)에서 밀면 1dp가 약 18초다. 조금 되감으려다 몇 분씩 튄다. 토렌트 재생은 튄 구간을 새로 받아야 해서, 잘못 탐색하면 기다림이 길어진다.

## 2. 원하는 동작
1. 스와이프 탐색은 영상 길이와 관계없이 화면 너비 = 최대 약 3분(영상이 3분보다 짧으면 전체 길이)으로 한다.
2. 탐색 미리보기 중 화면 가운데에 "+01:20 (00:45:10)"처럼 이동량과 목표 시간을 크게 보인다.
3. 재생 막대 드래그는 지금처럼 전체 길이 기준으로 둔다(큰 이동용).
4. 이동 목표가 아직 받지 않은 구간이면 미리보기에 "받지 않은 구간"을 표시한다(조각 맵 기준).

## 3. 완료 조건
- 2시간 영상에서 화면 너비의 10%를 밀면 약 18초(±3초) 이동한다.
- 미리보기에 이동량과 목표 시간이 함께 보인다.
- `SwipeSeek` 단위 테스트가 새 기준을 확인한다.

## 4. 범위 밖
- 썸네일 미리보기(받지 않은 구간은 만들 수 없음)
- 두 번 탭 이동량 설정(10초 고정 유지)

## 5. 영향
- design: 미리보기 표시(S)
- program: `SwipeSeek` 계산 변경과 테스트(S)
- 정책: 영향 없음.

## 결정 필요
- 최대 범위 3분이 적당한지(2분/5분)
