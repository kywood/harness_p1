# 요구사항: 영어 지원

## 1. 문제
앱 문구는 한국어뿐이다. 토렌트 스트리밍 앱 수요는 해외가 훨씬 크고, Play 스토어는 국가별로 노출된다. 기기 언어가 영어인 사용자는 한국어 화면을 보게 되어 바로 이탈한다. 대부분의 문구는 이미 `strings.xml`에 있어 번역 준비는 절반쯤 되어 있으나, ViewModel·다운로드 관리·입력 해석·엔진 단계 문구·재생 시간 표기("현재 … / 전체 …") 등은 코드에 한국어로 남아 있다.

## 2. 원하는 동작
1. 기기 언어가 한국어가 아니면 영어로 보인다(기본 언어 한국어 유지 여부는 결정 필요).
2. 모든 사용자 문구(오류, 상태, 단계, 시간 표기, 알림)가 두 언어로 나온다.
3. 날짜·용량·속도 표기는 기기 지역 형식을 따른다.
4. 스토어 등록정보 영어판을 함께 준비한다(launch).

## 3. 완료 조건
- 기기 언어를 English로 바꾸고 다섯 화면과 오류를 돌려 봤을 때 한국어 문구가 하나도 없다.
- 코드 안 한국어 사용자 문구 0개(린트 또는 테스트로 확인).
- 영어 문구가 버튼·칩에서 잘리지 않는다.

## 4. 범위 밖
- 세 번째 언어, 앱 안 언어 선택 메뉴(Android 13 앱별 언어 설정은 지원 고려)

## 5. 영향
- design: 영어 문구 작성·검토, 긴 문구 배치 점검(M)
- program: 남은 문구 리소스화([error-recovery.md](error-recovery.md)와 겹침), `values-en` 또는 기본/한국어 분리(M)
- launch: 영어 등록정보, 국가별 출시 범위
- 정책: 출시 국가를 넓히면 국가별 광고 동의(UMP)·콘텐츠 등급 확인 필요. 데이터 보안 신고 변경 없음.

## 결정 필요
- 기본 언어(values/)를 영어로 바꾸고 한국어를 `values-ko`로 옮길지
- 첫 출시 국가 범위
