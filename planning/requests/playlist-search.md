# 요구사항: 재생 목록 검색과 항목 탭

## 1. 문제
- 재생 목록이 30~50개가 되면 원하는 영상을 찾는 방법이 정렬 두 가지뿐이다.
- 항목 카드 자체를 눌러도 반응이 없어 보인다(재생 버튼만 동작, 미확인). 일반적인 목록 앱은 항목 탭으로 재생하거나 상세를 연다.

## 2. 원하는 동작
1. 재생 목록 상단 바에 검색 아이콘. 누르면 검색창이 열리고, 입력할수록 제목에 그 글자가 든 항목만 남는다(대소문자·공백 무시).
2. 항목 카드를 탭하면 재생한다(재생 버튼과 같음). 길게 누르면 선택 모드(체크박스)로 들어간다.
3. 검색 결과가 없으면 "'검색어'에 맞는 영상이 없습니다."

## 3. 완료 조건
- 50개 목록에서 제목 일부로 검색하면 맞는 항목만 남는다.
- 카드 탭으로 재생이 시작된다.
- 검색어는 저장하지 않는다.

## 4. 범위 밖
- 폴더·태그·즐겨찾기, 목록 한도(50개) 변경

## 5. 영향
- design: 검색창, 카드 탭·길게 누르기 동작(S)
- program: 거르기 순수 객체와 테스트(S)
- 정책: 영향 없음.
