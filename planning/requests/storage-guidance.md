# 요구사항: 저장 공간 안내와 정리

## 1. 문제
- 영상은 앱 전용 저장소(`noBackupFilesDir`)에 쌓이고 캐시 삭제로도 지워지지 않는다. 사용자는 기기에 공간이 얼마나 남았는지, 앱이 얼마를 쓰는지 메인에서 알 수 없다.
- 큰 영상(수 GB)을 받기 전에 공간이 충분한지 확인하지 않는다. 공간이 차면 어떤 문구가 나오는지 미확인(엔진 원문 오류로 추정).
- 재생 목록이 50개를 넘으면 오래된 항목이 목록에서 빠지지만 그 영상 파일은 저장 파일 관리에 남는 것으로 보인다(미확인). 사용자는 그 파일이 무엇인지 알 수 없다(경로가 64자리 키).
- 저장 파일 관리에 `.bin` 진행 정보가 섞여 보이고, 영상 단위가 아니라 파일 단위로 지운다. 재생 목록 삭제와 단위가 달라 헷갈린다.
- 다운로드 중이면 삭제가 막히는데 그 화면에서 중지할 수 없다.

## 2. 원하는 동작
1. 저장 파일 관리 맨 위에 "PiecePlay 사용 N GB · 기기 남은 공간 M GB" 막대를 보인다.
2. 저장 파일 관리를 영상 단위로 묶는다: 행 하나 = 영상 하나(제목은 재생 목록 제목, 없으면 파일 이름), 크기는 영상+진행 정보 합계. 펼치면 실제 파일 목록. `.bin`은 "진행 정보"로 이름을 바꿔 보인다.
3. 재생 목록에 없는 영상(목록에서 빠진 것)은 "재생 목록에 없는 파일" 묶음으로 따로 보이고 한 번에 지울 수 있다.
4. 다운로드 시작 시 남은 공간이 영상 크기 + 여유분(예: 500MB)보다 작으면 준비 화면에서 멈추고 "저장 공간이 부족합니다. N GB가 필요합니다." + "저장 파일 관리" 버튼을 보인다.
5. 다운로드 중이라 삭제가 막히면 문구와 함께 "다운로드 모두 중지" 버튼을 바로 보인다.
6. 메인 "저장 파일 관리" 카드의 보조 문구를 "N GB 사용 중"으로 바꾼다.

## 3. 완료 조건
- 저장 파일 관리에서 앱 사용량과 기기 남은 공간이 보인다.
- 남은 공간보다 큰 영상은 다운로드를 시작하지 않고 공간 부족 문구가 보인다.
- 재생 목록에서 빠진 항목의 파일을 찾아 지울 수 있다.
- 영상 행 하나를 지우면 그 영상의 영상·진행 정보가 함께 지워지고, 재생 목록 항목은 남는다(다시 받으면 처음부터).

## 4. 범위 밖
- 외부 저장소(SD 카드·다운로드 폴더)로 저장 위치 변경, 다른 앱으로 내보내기
- 자동 정리(오래된 파일 자동 삭제)

## 5. 영향
- design: 저장 공간 막대, 영상 단위 묶음 행, 공간 부족 상태(M)
- program: 남은 공간 조회, 시작 전 공간 확인(engine 작은 변경), 키 → 제목 묶기, 목록에 없는 파일 판별(M)
- 정책: 저장소 권한 불필요(앱 전용 저장소). 데이터 보안 신고 변경 없음. 저장 파일 관리 화면에는 광고를 넣지 않는다(유지).

## 결정 필요
- 재생 목록 50개 한도를 넘을 때 빠지는 항목의 파일을 함께 지울지, 지금처럼 남기고 "목록에 없는 파일"로 보여 줄지
- 공간 여유분 기준(고정 500MB / 기기 용량의 5%)
