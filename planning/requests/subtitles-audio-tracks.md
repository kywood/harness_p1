# 요구사항: 자막·오디오 트랙 선택과 토렌트 안 자막 파일

## 1. 문제
- 재생 화면에 자막·오디오 트랙 선택이 없다. MKV처럼 자막·음성이 여러 개 든 영상에서 원하는 언어를 고를 수 없다(VLC 기본 선택이 무엇인지는 미확인).
- 엔진은 토렌트 안 가장 큰 영상 하나만 받고 나머지는 받지 않는다. 같은 토렌트에 든 `.srt`·`.ass`·`.smi` 자막 파일은 절대 받지 못한다. 한국 사용자는 외부 자막(특히 `.smi`·`.srt`)을 많이 쓴다.

## 2. 원하는 동작
1단계 (내장 트랙)
1. 재생 화면 상단에 "자막" 버튼(또는 더보기 시트 항목)이 있다.
2. 누르면 시트에 자막 트랙 목록("끄기", 트랙 이름/언어)과 오디오 트랙 목록이 보인다. 현재 선택에 표시가 있다.
3. 고르면 바로 바뀌고, 같은 영상을 다시 열면 마지막 선택을 기억한다.

2단계 (토렌트 안 자막 파일)
4. 메타데이터를 받을 때 영상과 같은 이름(또는 같은 폴더)의 자막 파일이 있으면 영상과 함께 받는다(자막 파일은 작으므로 우선 받는다).
5. 받은 자막은 자막 시트에 "파일: 이름.srt"로 보이고, 하나뿐이면 자동으로 켠다.

## 3. 완료 조건
- 자막 2개·음성 2개가 든 MKV에서 각각 바꿀 수 있고, 다시 재생하면 선택이 유지된다.
- 영상+`.srt`가 든 토렌트에서 자막 파일을 받아 표시할 수 있다(2단계).
- 자막 파일을 받아도 다른 영상·기타 파일은 여전히 받지 않는다.
- 트랙이 없으면 시트에 "자막 없음"이 보인다.

## 4. 범위 밖
- 자막 검색·다운로드(외부 서비스), 자막 싱크 조절·글자 크기(후속 후보)
- 기기 파일에서 자막 직접 불러오기(저장소 접근 필요 → 별도 검토)

## 5. 영향
- design: 자막·오디오 시트, 상단 버튼 배치(M)
- program: 1단계 VLC 트랙 조회·선택(M), 2단계 엔진의 파일 선택 규칙 변경(engine 규칙상 작은 변경 여러 번, M~L)
- 정책: 트랙 선택 기억은 기기 안 재생 목록 항목에 저장한다면 `MagnetHistory` 포맷 버전 증가 필요(암호화 유지). 기기 밖 전송 없음 → 데이터 보안 신고 변경 없음. 2단계는 "선택한 영상 하나만 받는다"는 기존 안내(패치 노트·스토어 설명)를 "영상과 그 자막"으로 고쳐야 한다.

## 결정 필요
- 1단계만 먼저 할지, 2단계까지 한 번에 할지
- 선택 기억을 영상별로 할지, "선호 언어" 전역 하나로 할지
