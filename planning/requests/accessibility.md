# 요구사항: 접근성 (TalkBack·글자 크기·대비)

## 1. 문제
코드를 읽은 범위의 관찰이며, 실제 TalkBack 확인은 하지 않았다(미확인).
- 조각 맵·진행 막대는 그림뿐이라 화면 읽기 사용자에게 진행 정도가 전달되지 않을 수 있다.
- 준비 화면 단계 표시(정보 → 연결 → 버퍼링)는 점 색으로 현재 단계를 구분한다. 색만으로 상태를 나타낸다.
- 재생 화면 조작 UI는 3.5초 뒤 사라진다. 화면 읽기 사용 중에도 사라지면 버튼을 찾기 어렵다.
- 재생 시간이 "현재 00:12 / 전체 01:40:00" 형식의 숫자 문자열이라 읽기가 부자연스럽다.
- 상태 칩(다운로드 중/완료/실패)은 색과 글자를 함께 쓰므로 괜찮다. 확대 배율 버튼은 설명이 있다.
- 시스템 글자 크기를 크게 하면 재생 목록 카드·버튼 줄이 넘칠 수 있다(미확인).

## 2. 원하는 동작
1. 조각 맵·진행 막대는 "다운로드 35%, 조각 120개 중 42개"처럼 읽힌다.
2. 단계 표시는 "3단계 중 2단계, 연결"처럼 읽힌다.
3. TalkBack이 켜져 있으면 재생 조작 UI가 자동으로 숨지 않는다.
4. 재생 시간은 "12초 / 1시간 40분"처럼 읽힌다.
5. 글자 크기 200%에서 메인·재생 목록·준비 화면이 잘리지 않는다(줄바꿈·스크롤).
6. 모든 터치 대상이 48dp 이상이다.

## 3. 완료 조건
- Android 접근성 검사기(Accessibility Scanner)로 다섯 화면에 중대 경고가 없다.
- TalkBack만으로 링크 붙여넣기 → 재생 → 일시 정지 → 10초 앞으로 → 뒤로가 가능하다.
- 글자 크기 최대에서 화면 캡처로 잘림이 없다.

## 4. 범위 밖
- 고대비 별도 테마, 음성 명령

## 5. 영향
- design: 대체 텍스트 문구, 큰 글자 배치 점검(M)
- program: 의미 정보(semantics) 추가, TalkBack 감지 시 자동 숨김 끄기, 에뮬레이터 테스트(M)
- 정책: 영향 없음. 스토어 품질 평가와 리뷰에 긍정적.
