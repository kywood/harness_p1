# 요구사항: 재생 화면 편의(화면 잠금·밝기/음량 제스처·화면 속 화면)

## 1. 문제
- 누워서 보거나 이동 중에 손이 닿으면 탭·스와이프로 탐색이 일어난다. 잠금이 없다.
- 일반 동영상 앱 사용자는 화면 왼쪽/오른쪽 세로 스와이프로 밝기·음량을 바꾸는 데 익숙하다. 지금은 세로 스와이프에 동작이 없다.
- 다른 앱을 잠깐 보려면 재생을 나가야 한다(화면 속 화면 없음).

## 2. 원하는 동작
1. 조작 UI에 "잠금" 버튼. 잠그면 모든 제스처·버튼이 막히고, 탭하면 "잠금 해제" 버튼만 잠시 보인다.
2. 화면 왼쪽 절반 세로 스와이프 = 밝기(앱 창 밝기만, 시스템 설정은 바꾸지 않음), 오른쪽 절반 = 음량. 바꾸는 동안 가운데에 값 표시.
3. 재생 중 홈으로 나가면 화면 속 화면으로 작게 이어서 재생한다(설정으로 끌 수 있음). 화면 속 화면에서도 다운로드는 이어진다.

## 3. 완료 조건
- 잠금 상태에서 스와이프·두 번 탭·버튼이 동작하지 않는다.
- 세로 스와이프로 밝기·음량이 바뀌고, 재생 화면을 나가면 밝기가 원래대로 돌아온다.
- 화면 속 화면에서 재생·일시 정지가 되고, 닫으면 재생 위치가 저장된다.

## 4. 범위 밖
- 백그라운드 오디오만 재생, 크롬캐스트

## 5. 영향
- design: 잠금·값 표시 오버레이, 화면 속 화면 조작(M)
- program: 제스처 구분(가로 탐색과 충돌 방지), PiP 진입·복귀, 수명주기(재생 위치 저장·엔진 유지) 처리(L에 가까운 M)
- 정책: 권한 추가 없음(밝기는 창 단위, 시스템 설정 권한 불필요). 화면 속 화면 중 광고 없음 유지. 데이터 보안 신고 변경 없음.

## 결정 필요
- 세 기능을 나눠 출시할지(잠금 S → 제스처 S → PiP M 순서 권장)
