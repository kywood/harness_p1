# 요구사항: 이어보기 개선 (메인 바로가기·시작 안내)

## 1. 문제
- 이어볼 위치는 재생 목록 안에만 보인다. 앱을 다시 연 사용자는 메인 → 재생 목록 → 항목 찾기 → 재생을 거쳐야 한다.
- 재생을 시작하면 말없이 저장 위치로 이동한다. 사용자는 왜 중간부터 나오는지 모르고, 처음부터 보려면 더보기 → "재생 위치 초기화 · 처음부터"를 찾아야 한다.

## 2. 원하는 동작
1. 메인 **바로가기 카드(재생 목록·저장 파일 관리) 위**에 "이어보기" 카드가 보인다(입력 → 바로 재생 흐름을 끊지 않도록, design 의견 반영): 마지막으로 보던 영상 1개(이어볼 위치가 있고 끝까지 보지 않은 것), 제목, "00:45:10부터", 진행 막대. 누르면 재생 목록에서 재생한 것과 같이 시작한다(닫으면 재생 목록으로).
2. 이어볼 위치로 이동했으면 재생 화면 아래 패널 위 왼쪽에 3초간 안내가 보인다: "00:45:10부터 이어서 재생합니다" + "처음부터".
3. 이어볼 항목이 없으면 카드를 보이지 않는다.
4. 카드 오른쪽 위 "숨기기"(×)를 누르면 **다음 시청 전까지** 카드가 숨는다(Q8). 다른 영상을 보거나 같은 영상을 다시 보면 다시 나온다. 영구 끄기는 설정 화면이 생길 때 설정 항목으로 옮긴다.

## 3. 완료 조건
- 영상을 중간에 닫고 앱을 다시 열면 메인에 이어보기 카드가 있고, 한 번 탭으로 같은 위치에서 재생된다.
- 이어보기 안내의 "처음부터"를 누르면 0초부터 재생되고 위치가 0으로 저장된다.
- 끝까지 본 영상은 카드에 나오지 않는다.
- "숨기기" 뒤 앱을 다시 열어도 카드가 보이지 않고, 다음 재생 후에는 다시 보인다.

## 4. 범위 밖
- 이어보기 여러 개 가로 목록, 홈 화면 위젯·앱 바로가기(후속)
- 다음 회차 자동 재생

## 5. 영향
- design: 메인 카드·재생 화면 안내(S~M)
- program: 마지막 시청 항목 고르기(순수 객체 + 테스트), 안내 표시(S)
- 정책: 이미 저장하는 이어보기 위치를 메인에 보여 줄 뿐. 저장 항목 추가 없음 → 데이터 보안 신고 변경 없음. 메인 배너 광고 위치는 그대로.
- 개인정보: 다른 사람이 앱을 열면 마지막 시청 제목이 메인에 보인다. "숨기기"(다음 시청 전까지)로 대응하고, 숨김 여부는 기기 안 값 하나로 저장한다(데이터 보안 신고 변경 없음).

## 결정 필요
- 없음(Q8 답으로 정리). 영구 끄기는 설정 화면 승인 때 다시 본다.
