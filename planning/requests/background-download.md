# 요구사항: 앱을 떠나도 이어지는 다운로드

## 1. 문제
다운로드 작업은 화면(ViewModel) 안에서만 산다. 재생 목록에서 "받아 두기"를 걸고 앱을 나가면 시스템이 프로세스를 정리하는 순간 멈추고, 다시 열어도 자동으로 이어 받지 않는다. 사용자는 "받아 놨다"고 생각했다가 나중에 미완료 상태를 보고 실망한다. 다운로드 진행 알림도 없어 진행을 확인하려면 앱을 열어야 한다.

## 2. 원하는 동작
1. 재생 목록에서 다운로드가 하나라도 진행 중일 때 앱을 나가면, 알림 하나가 "PiecePlay 다운로드 중 · 2개 · 1.2 MB/s"로 남고 다운로드가 이어진다.
2. 알림에서 "모두 중지"를 누를 수 있고, 알림을 누르면 재생 목록이 열린다.
3. 모든 다운로드가 끝나면 알림이 "다운로드 완료 · 2개"로 바뀌고 계속 받지 않는다(시딩 차단 유지).
4. 앱이 강제 종료됐다가 다시 열리면, 끝나지 않은 다운로드 작업을 "이어 받을까요?" 한 줄로 묻는다(자동 재개는 하지 않음).
5. Android 13 이상에서는 처음 백그라운드 다운로드가 필요할 때 알림 권한을 묻는다. 거부해도 앱 안 다운로드는 그대로 동작한다.

## 3. 완료 조건
- 다운로드 중 홈으로 나가 30분 뒤 돌아와도 다운로드가 이어졌다(진행률 증가).
- 알림의 "모두 중지"로 모든 작업이 멈춘다.
- 다운로드 완료 후 업로드·공유 목록 등록이 일어나지 않는다(기존 테스트 유지).
- 재생 중 영상 재생은 백그라운드로 가면 지금처럼 멈춘다(오디오 백그라운드 재생은 범위 밖).

## 4. 범위 밖
- 예약 다운로드, Wi-Fi 전용 조건([mobile-data-guard.md](mobile-data-guard.md)에서 다룸)
- 백그라운드 오디오 재생

## 5. 영향
- design: 알림 문구·아이콘, 이어 받기 질문(S)
- program: 포그라운드 서비스로 다운로드 관리자 이동, 알림, 재개 질문(L). 엔진·다운로드 관리 구조 변경이 커서 별도 이슈 여러 개 권장.
- 정책: **영향 큼**
  - 권한 추가: `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_DATA_SYNC`, `POST_NOTIFICATIONS`.
  - Play Console "포그라운드 서비스 권한" 신고와 사용 사례 설명(동영상 데모 요구 가능)이 필요하다. Android 15부터 `dataSync` 유형은 하루 실행 시간 제한(약 6시간)이 있어 대안(`WorkManager` 장기 작업 등)을 program이 검토해야 한다.
  - 데이터 보안 신고: 수집 항목 변경 없음.
  - 출시 직전에 넣으면 심사 항목이 늘어나므로 출시 후 업데이트로 권장한다.

## 결정 필요
- 출시 후 첫 업데이트에 넣을지
- 앱 강제 종료 후 자동 재개를 할지(지금 제안은 묻기만 함)
