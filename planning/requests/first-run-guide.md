# 요구사항: 첫 사용 안내

## 1. 문제
처음 설치한 사용자는 메인에 입력란 하나만 본다. 마그넷 링크가 무엇인지, `.torrent` "다운로드 링크"는 파일 주소여야 한다는 것, 받으면서 재생되므로 처음 몇 초~몇 분은 기다릴 수 있다는 것, 피어가 없으면 재생이 안 된다는 것을 알 수 없다. 첫 시도가 120초 타임아웃으로 끝나면 앱이 고장 났다고 여기고 이탈하기 쉽다.

## 2. 원하는 동작
1. 첫 실행 시 UMP 동의 창(필요한 지역)이 끝난 뒤, 메인 위에 짧은 안내가 한 번 뜬다(3장 이하, 건너뛰기 가능).
   - 1장: "마그넷 링크나 .torrent 파일 주소를 붙여넣으면 받으면서 바로 재생합니다."
   - 2장: "공유 중인 사용자가 많을수록 빨리 시작합니다. 영상 하나만 받고, 다른 사람에게 올려 보내지 않습니다."
   - 3장: "받은 영상은 재생 목록에서 이어보고, 저장 파일 관리에서 정리합니다." + 이용 안내 한 줄([policy-notice-and-privacy.md](policy-notice-and-privacy.md))
2. 입력란이 비어 있을 때 보조 문구(placeholder)로 예시 형식 "magnet:?xt=urn:btih:…"를 보인다.
3. 메인에 "도움말"(물음표) 진입점을 두어 안내를 다시 볼 수 있다.

## 3. 완료 조건
- 새 설치 첫 실행에서 안내가 한 번 보이고, 닫은 뒤 다시 실행하면 보이지 않는다.
- 도움말에서 같은 안내를 다시 열 수 있다.
- 안내 화면에는 광고가 없다.
- TalkBack으로 모든 장을 읽고 넘길 수 있다.

## 4. 범위 밖
- 샘플(시연용) 마그넷 제공: 합법 공개 영상이라도 링크 유지 책임이 생기므로 PM 결정 사항으로 남긴다.
- 동영상 튜토리얼

## 5. 영향
- design: 안내 장 구성·그림·문구(M에 가까운 S)
- program: 한 번 보였는지 기록(기기 안 설정 값 하나), 도움말 진입(S)
- 정책: 기기 안 설정 값 하나 추가. 기기 밖으로 보내지 않으므로 데이터 보안 신고 변경 없음.

## 결정 필요
- 샘플 마그넷(예: 공개 라이선스 영상)을 안내에 넣을지
