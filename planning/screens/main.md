# 화면: 메인

코드: `ui/screens/MainScreen.kt` `MagnetLinkInputScreen` / `AppScreen.Main(errorMessage)`

## 목적
링크를 넣고 바로 재생을 시작한다. 재생 목록·저장 파일 관리로 가는 출발점.

## 진입
- 앱 실행(항상 여기서 시작)
- 메인에서 시작한 재생·준비를 닫았을 때, 재생 목록·저장 파일 관리에서 뒤로

## 보여 줄 정보
- 로고, "PiecePlay", "받으면서 바로 재생"
- 입력란 "마그넷 또는 .torrent 다운로드 링크", 아래에 오류 문구
- 하단 버전명, (동의 필요 지역) "광고 개인정보 설정"
- 배너 광고(화면 맨 아래)

## 동작
| 동작 | 결과 |
|---|---|
| 붙여넣기 | 클립보드 첫 항목을 입력란에 넣음(앞뒤 공백 제거) |
| 바로 재생 | 준비 화면으로 |
| 재생 목록 카드("받은 영상 모아 보기") | 재생 목록 |
| 저장 파일 관리 카드("저장 용량 정리") | 저장 파일 관리 |
| 광고 개인정보 설정 | UMP 개인정보 옵션 창 |

## 빈 상태
- 첫 실행에도 안내가 없다. 마그넷이 무엇인지, 어디서 얻는지, 합법 콘텐츠만 쓰라는 안내가 없다 → [requests/first-run-guide.md](../requests/first-run-guide.md), [requests/policy-notice-and-privacy.md](../requests/policy-notice-and-privacy.md)

## 오류 상태
- `AppScreen.Main(errorMessage)`: 입력란 아래 빨간 문구. 문구 목록은 spec §12.
- 실패 후 입력란 내용이 남는지는 미확인(준비 화면을 거친 실패는 비는 것으로 보임).
- "다시 시도" 버튼은 없다.

## 없는 것
- 최근 보던 영상 이어보기 바로가기, 설정 진입점, 도움말, 개인정보처리방침 링크
