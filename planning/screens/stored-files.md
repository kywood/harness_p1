# 화면: 저장 파일 관리

코드: `ui/StoredFilesScreen.kt` / `AppScreen.StoredFiles`

## 목적
앱이 기기에 쓴 파일(영상, 암호화된 진행 정보)을 보고 지워 공간을 확보한다.

## 진입
- 메인 "저장 파일 관리" 카드. 들어갈 때 진행 중인 재생 스트림을 멈춘다.

## 보여 줄 정보
- 상단 바: "저장 파일 관리", 닫기, 새로고침
- 요약: "N개 · 합계 용량"(현재 필터 기준), "다운로드 파일과 암호화된 진행 정보"
- 확장자 칩: 전체 / .확장자 / 확장자 없음
- 읽는 중 진행 막대
- 일괄 선택 줄
- 파일 행: 형식 아이콘, 파일 이름(`torrent_downloads/<64자리 키>/…` 형태의 상대 경로), 크기, 체크박스, 삭제
- 광고 없음

## 동작
| 동작 | 결과 |
|---|---|
| 삭제 | 확인 창 "이 파일을 삭제할까요?" + 파일 이름 + "삭제하면 해당 파일을 다시 받아야 할 수 있습니다." |
| 선택 삭제 | 확인 창 "선택한 실제 파일을 삭제합니다…" |
| 새로고침 | 다시 읽기 |

## 빈 상태
- "저장된 파일이 없습니다." / "해당 확장자의 파일이 없습니다."

## 오류 상태
- 읽기 실패 "파일 목록을 읽지 못했습니다.", 삭제 실패 "파일이 없거나 삭제할 수 없습니다." / "삭제하지 못했습니다."
- 다운로드 중 삭제 시도: "파일을 삭제하려면 먼저 재생 목록의 다운로드를 중지해 주세요."
- 재생 중 파일 삭제 시도: 엔진의 영어 원문 "Stop playback or downloading before deleting this file"이 보일 수 있다(코드상 `require` 메시지, 미확인).

## 부족한 점
- 기기 남은 공간 표시 없음, 파일이 어느 영상의 것인지 알기 어려움(64자리 키 경로), `.bin` 내부 파일 노출
