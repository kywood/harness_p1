# 화면: 재생 목록

코드: `ui/MagnetHistoryScreen.kt` / `AppScreen.Playlist`

## 목적
재생하거나 받은 영상을 모아 보고, 이어보기·다운로드 관리·삭제를 한다.

## 진입
- 메인 "재생 목록" 카드, 준비 화면 "재생 목록", 재생 목록에서 시작한 재생을 닫았을 때, 끝까지 재생했을 때

## 보여 줄 정보
- 상단 바: 제목 "재생 목록", 닫기, "링크 추가", "간단히/자세히"
- 요약: "다운로드 중 N개( · 대기 N개)", 받는 중이면 "다운로드 중지"/"전체 중지", "최근 50개를 암호화해 보관합니다."
- 칩: "정렬: 최근 재생순/받은 날짜순", "표시: 전체/다운로드 완료/다운로드 미완료"
- 오류 줄: 목록 읽기 실패("목록을 읽지 못했습니다." + 다시 시도), 삭제·초기화 실패, 다운로드 오류
- 일괄 선택 줄: 전체 선택, 다운로드/중지, 선택 삭제 (N)
- 항목 카드: 제목(2줄), 체크박스, 상태 칩, 받은 양/크기·속도, 진행 막대, (자세히) 조각 맵·받은 날짜·마그넷 주소, 이어보기 시간·위치 초기화, 항목 오류, 재생·다운로드 버튼·삭제 아이콘
- 배너 광고(화면 맨 아래)

## 동작
| 동작 | 결과 |
|---|---|
| 재생 | 준비 화면 → 재생, 닫으면 여기로 |
| 다운로드/중지/대기 취소 | 작업 시작·중지 |
| 위치 초기화 | 이어보기 위치 0 |
| 삭제 아이콘 | 확인 창 "영상 파일과 함께 삭제할까요?" → 다운로드 중지, 영상·메타데이터·이어받기 기록·항목 삭제 |
| 링크 추가 | 링크 추가 대화상자 |
| 다운로드 중이면 | 2초마다 목록 새로 읽기 |

## 빈 상태
- 목록 없음: 아이콘 + "재생 목록이 비어 있습니다." + "링크 추가" 버튼
- 필터 결과 없음: "해당 조건의 영상이 없습니다."

## 오류 상태
- 위 오류 줄. 엔진 오류 원문이 그대로 보일 수 있다(예: "토렌트 처리 중 오류가 발생했습니다: …").

## 부족한 점
- 검색 없음, 50개 한도 안내 부족, 항목을 눌러도 아무 일 없음(재생 버튼만 동작, 미확인: 카드 탭 동작 없음으로 보임)
- 실패 항목에 "다시 시도"가 따로 없다(다운로드 버튼으로 다시 시작은 가능)
