# 화면: 준비 화면

코드: `ui/screens/PreparingScreen.kt` / `AppScreen.Preparing.FetchingMetadata`, `AppScreen.Preparing.Buffering`

## 목적
토렌트 정보를 받고 재생 시작 구간을 버퍼링하는 동안 진행을 보여 준다.

## 진입
- 메인 "바로 재생", 재생 목록 "재생"

## 보여 줄 정보
- 파일 이름(받기 전 "파일 이름 확인 중")
- 단계 표시: 정보 → 연결 → 버퍼링
- 진행 카드
  - 정보·연결 단계: "토렌트 정보 가져오는 중…" / "토렌트 정보 수신 완료", 끝이 없는 진행 막대, 피어 칩, "파일 정보와 연결 상태를 확인합니다."
  - 버퍼링 단계: "버퍼링: N%", 진행 막대, 속도 칩, 피어 칩
- 조각 맵(파일 앞 → 뒤)
- 세부 정보(접힘): 정보 출처, 연결 피어, 파일 수·크기, 피스 수·크기, 받은 영상 크기, 단계 문구(엔진이 주는 한국어 원문, 피어 탐색 경과 시간 포함)

## 동작
| 동작 | 결과 |
|---|---|
| 메인 | 다운로드 멈추고 메인 |
| 재생 목록 | 재생만 멈추고 다운로드는 이어 가며 재생 목록 |
| 뒤로(시스템) | 시작한 곳으로, 메인에서 시작했으면 다운로드도 멈춤 |
| 세부 정보 펼치기/접기 | — |

## 빈 상태
- 메타데이터 전: 조각 맵 "피스 정보 확인 전", 세부 정보 "메타데이터 수신 전에는 파일 크기와 피스 배치를 알 수 없습니다."

## 오류 상태
- 이 화면에는 오류 표시가 없다. 실패하면 메인(또는 시작한 곳이 아닌 메인)으로 돌아가 문구를 보인다.

## 부족한 점
- 최대 120초를 기다리는데 경과·남은 시간, "피어가 없으면 못 받을 수 있음" 같은 기대치 안내가 본문에 없다(세부 정보 안에만 경과 시간).
- 피어 0명이 오래 이어질 때 할 수 있는 일(재생 목록에서 계속 받기, 다른 링크 시도)을 권하지 않는다.
