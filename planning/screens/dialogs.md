# 화면: 대화상자

## 링크 추가 (`ui/QuickDownloadDialog.kt`)
- 목적: 재생 없이 다운로드 작업을 추가한다.
- 진입: 재생 목록 "링크 추가", 빈 재생 목록의 "링크 추가", 재생 화면 더보기 → "링크 추가"
- 정보: 제목 "링크 추가", 입력란 "마그넷 또는 .torrent 링크", 처리 중 진행 막대, 오류 문구
- 동작: "다운로드"(입력이 있을 때만) → 해석 성공 시 닫히고 작업 추가 / "취소"
- 오류: 해석 실패 문구 또는 "주소를 확인해 주세요." 붙여넣기 버튼은 없다(메인과 다름).

## 삭제 확인 (`ui/components/ConfirmDialog.kt`)
- 재생 목록 한 개: "영상 파일과 함께 삭제할까요?" / "이 항목의 다운로드를 중지하고 영상·메타데이터·이어받기 기록을 모두 삭제합니다. 복구할 수 없습니다."
- 재생 목록 여러 개: "N개 항목을 삭제할까요?" / 같은 취지 문구
- 저장 파일 한 개·여러 개: [stored-files.md](stored-files.md)
- 동작: "삭제"(진행 중 "삭제 중…") / "취소"
