# PiecePlay 패치 노트

## v.2026.11.01.008 (versionCode 18)

- 재생 준비 중 `재생 목록`으로 이동해도 같은 다운로드를 계속 유지합니다.
- `메인`으로 이동하면 현재 다운로드만 중지하고 다른 다운로드는 유지합니다.
- 여러 다운로드를 함께 관리하고 대기 중인 작업을 순서대로 시작합니다.
- 다운로드 작업들이 하나의 libtorrent 세션을 공유하도록 개선했습니다.
- 전체 선택 후 다운로드 시 발생하던 네이티브 충돌을 수정했습니다.
- 선택 작업을 `전체 선택 · 삭제 · 다운로드/중지` 한 줄로 정리했습니다.
- 재생 목록에 최근 재생순·받은 날짜순 정렬과 완료 여부 필터를 추가했습니다.
- 완료 파일 재생 전환 및 다운로드 파일 삭제 시 작업 간 충돌을 개선했습니다.
- 가로 화면의 재생 정보와 피스 범례를 간결하게 표시합니다.
- 재생 UI가 보일 때만 좌우 스와이프로 탐색하고 확대 화면 이동은 유지합니다.
- 준비 화면 버튼을 `메인`과 `재생 목록`으로 구분했습니다.
- 날짜와 당일 수정 횟수에 따른 버전 관리 및 APK/AAB 출력 기능을 추가했습니다.

검증: 단위 테스트 201개, 관련 에뮬레이터 테스트 11개 통과(v007 코드 기준).
출시 빌드: v008 버전 검증·단위 테스트 201개·서명 APK/AAB 빌드 통과.
